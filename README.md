# Toshalia

Toshalia is a free minimap overlay for [Palia](https://palia.com). It is not made or supported by Singularity 6.

Download Toshalia only from [Releases](../../releases).

## Check the Discord server for important information before downloading

https://discord.gg/yVuTdkwq9v

## Check your download

Compare `Get-FileHash <installer>` in PowerShell with `SHA256SUMS.txt`. If the hashes are different, do not run the file.

## Risks

Third-party tools are against the Palia terms of service. Use Toshalia at your own risk.
